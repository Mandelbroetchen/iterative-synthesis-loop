## Part 4: Output Format (STRICT)

**You must respond with exactly one file: `overwrite.py`**

Requirements:
- Pure Python code only (no explanations, comments, or additional text)
- All files listed in `.overwrite.json` must be included
- Complete, production-ready content for each file
- UTF-8 encoding
- Creates directories if needed
- Successfully executes without errors

**Template Structure**:

```python
from pathlib import Path

files = {
    "prompt-final/document.md": """[Complete markdown content]""",
    "prompt-final/usecase-diagram.uml": """[Complete PlantUML diagram]""",
    "prompt-final/package-diagram.uml": """[Complete PlantUML diagram]""",
    "prompt-final/class-diagram.uml": """[Complete PlantUML diagram]"""
}

for path, content in files.items():
    Path(path).parent.mkdir(parents=True, exist_ok=True)
    Path(path).write_text(content, encoding="utf-8")

print("✓ All files updated successfully")
```

Do not include any additional output or explanation beyond the Python code.
